## 👨‍💻 About Me

Hi! I'm Lucas, a software developer from Brazil with a **hybrid profile combining software development and SaaS sales**.

- 💻 I work mainly with **Java, Kotlin and Spring Boot**, building REST APIs, business rules, authentication flows, and database integrations.
- 🌐 I also develop **front-end applications with React**, focused on consuming APIs and delivering clean, functional user interfaces.
- 📦 I use **Docker** to run backend services and databases locally, keeping development environments consistent and reproducible.
- 🤖 I have hands-on experience with **facial biometrics**, including face capture, liveness detection, and API integration.
- 📊 I’ve worked with **data analysis and dashboards** using **Power BI**, as well as automation scripts in **Python** and **VBA**.
- 💼 Currently, I work as a **Key Account Partner at Bizneo HR**, acting in **software sales, partnerships, and customer-facing technical discussions**.
- 🧠 Through this role, I’ve developed solid knowledge of **HRIS systems**, HR workflows, compliance requirements, and how SaaS platforms support people management.

I enjoy building systems end-to-end and connecting **technology with real business needs** — from backend logic to the value delivered to users and companies.
